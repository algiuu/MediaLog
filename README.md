## ✨ Fitur

| Fitur | Keterangan |
|:---|:---|
| 📝 Pencatatan Media | Catat film, serial, buku, atau game dengan detail lengkap |
| 🔍 Pencarian & Filter | Cari dan filter koleksi berdasarkan kategori atau status |
| 💾 Penyimpanan Lokal | Data aman tersimpan di perangkat (Room + DataStore) |
| 🎨 UI Modern | Material Design dengan navigasi intuitif |
| 📴 Offline-First | Semua data lokal, tidak butuh internet |

---

## 🛠 Tech Stack

| Kategori | Teknologi |
|:---|:---|
| 🗣 Bahasa | Kotlin |
| 🏗 Arsitektur | MVVM + Hilt (DI) |
| 🗄 Database | Room |
| 🌐 Networking | Retrofit + OkHttp |
| 🖼 Image Loading | Coil |
| ⚡ Async | Coroutines + WorkManager |

## 📦 Instalasi

> **Catatan:** Masih **debug build**, bukan untuk produksi.

### Persyaratan

- Android 8.0 (API 26) ke atas
- ~20 MB ruang penyimpanan

### Langkah

1. Download **APK (debug)** dari [Release](https://github.com/algiuu/MediaLog/releases)
2. Buka file APK di perangkat Android
3. Aktifkan **"Install dari sumber tidak dikenal"** jika diminta
4. Klik **Install** dan tunggu proses selesai

---

## 🚀 Quick Start

```
1. Buka aplikasi MediaLog
2. Tambah media baru dengan tombol "+"
3. Isi detail media (judul, tipe, status)
4. Simpan dan mulai catat koleksimu!
```

---

## 📋 Kebijakan

### Privasi
- Semua data tersimpan **lokal** di perangkat kamu
- Tidak ada data yang dikirim ke server eksternal
- Tidak ada iklan atau pelacakan

### Keamanan
- Data terenkripsi menggunakan Android Security Crypto
- Tidak butuh koneksi internet untuk fitur utama
